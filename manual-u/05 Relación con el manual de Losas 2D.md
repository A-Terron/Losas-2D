## Qué tiene cada hoja

| | Losas 2D | Losas 2D U |
|---|---|---|
| Geometría | Retícula fija de 3 × 3 tableros | Un tablero con sus vecinos |
| Una dirección | No | Sí (Cap. 7 y §6.5) |
| Dos direcciones | DDM, EFM y envolvente | DDM, EFM y envolvente |
| Apoyos | Vigas o columnas | Vigas, muros, columnas o borde libre, borde por borde |
| Punzonamiento | No | Sí, en columnas sin viga |
| Elementos finitos y ETABS | Sí | No |
| Verificación de fórmulas | [03 Verificación de fórmulas](https://a-terron.github.io/Losas-2D/manual/03%20Verificaci%C3%B3n%20de%20f%C3%B3rmulas/) | [[03 Validación]] |
