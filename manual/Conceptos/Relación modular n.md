# Relación modular n

**Qué es.** Cuántas veces más rígido es el acero que el concreto.

**Fórmula.** $n = E_s / E_c$

**Por qué.** Permite sustituir el área de acero $A_s$ por un área equivalente de concreto $n\,A_s$ y tratar la sección como si fuera de un solo material (sección transformada).

**Cómo.** $E_s$ = 29 000 ksi (ACI 20.2.2.2); $E_c$ de [[Módulo de elasticidad Ec]].

**En la HT1.** 29 000 / 3605 = 8.04.
