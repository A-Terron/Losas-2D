# Sección controlada por tensión

**Qué es.** Una sección en la que el acero fluye con holgura antes de que el concreto se aplaste: falla dúctil, con aviso.

**Criterio.**

$$\varepsilon_t = 0.003\,\frac{d - c}{c}\ \ge\ \varepsilon_{ty} + 0.003\qquad c = \frac{a}{\beta_1}$$

**Por qué.** Solo así se puede usar $\phi$ = 0.90. El Código exige que las losas en dos direcciones no presforzadas sean controladas por tensión.

**Cómo.** Con el acero **colocado** se calcula $a$, luego $c$ y $\varepsilon_t$.

**En la práctica.** Las losas tienen cuantías muy bajas, así que $\varepsilon_t$ suele ser 10 a 20 veces el límite. Si no se cumple, la losa es demasiado delgada.

**En la HT1.** $\varepsilon_{ty}$ + 0.003 = 0.0051; $\varepsilon_t$ ≈ 0.050.

**Referencia.** ACI 318-19 §8.3.3.1 y Tabla 21.2.2.
