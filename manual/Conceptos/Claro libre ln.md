# Claro libre ln

**Qué es.** La distancia entre caras de apoyos. Hay dos definiciones y no deben mezclarse:

| Uso | Se mide entre | Referencia |
|---|---|---|
| Espesor mínimo | Caras de **vigas** (o de apoyos si no hay vigas), en la dirección larga | Tablas 8.3.1.1 y 8.3.1.2 |
| Momento estático $M_o$ | Caras de **columnas**: $\ell_n = \ell_1 - c_1 \ge 0.65\,\ell_1$ | 318-14 §8.10.3.2.1 |
| Extensión de bastones | Caras de columnas | Fig. 8.7.4.1.3 |

![[F05-claros-libres-y-beta.svg]]

**Por qué.** El momento se genera en la luz libre; dentro del apoyo la losa no se flexiona igual.

**En la HT1.** Para espesor: 6.70 − 0.35 = 6.35 m. Para $M_o$: 6.70 − 0.50 = 6.20 m.
