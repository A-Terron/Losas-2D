# Combinaciones de carga y wu

**Qué es.** Las cargas de servicio multiplicadas por factores para obtener la carga última de diseño.

**Fórmulas.**

$$U_1 = 1.4\,D\qquad U_2 = 1.2\,D + 1.6\,L\qquad w_u = \max(U_1, U_2)$$

**Por qué.** Los factores cubren la incertidumbre de las cargas: la viva es menos predecible, por eso lleva 1.6.

**Cuándo usar cada carga.** $w_u$ para flexión y cortante. Cargas de **servicio** (sin factores) para deflexiones.

**En la HT1.** $w_D$ = 360 + 50 = 410; $w_L$ = 250; $U_1$ = 574; $U_2$ = 892 kgf/m² → gobierna $U_2$.

**Referencia.** ACI 318-19 Tabla 5.3.1.
